# /fask-loop — 다 묻고, 그다음 안 묻는다

`/full-loop` 은 **아무것도 안 묻고** 목표까지 간다. 그게 강점이자 위험이다 — 요구사항이 흐린 채로 출발하면, 흐린 방향으로 아주 효율적으로 달린다.

`/fask-loop` 은 그 앞에 인터뷰를 붙인다. **묻는 건 전부 앞에서 끝내고, 넘어간 다음에는 안 묻는다.**

```
/fask-loop <요청>
   │
   ├─ 1. fask 규약으로 결정이 마를 때까지 캐묻는다   ← 여기서만 묻는다
   ├─ 2. 합의를 goal 로 압축한다
   └─ 3. `Skill` 툴로 `full-loop` 을 바로 호출한다   ← 여기서부터 안 묻는다
```

## 왜 fask 는 인라인이고 full-loop 은 호출인가

`disable-model-invocation: true` 인 스킬은 **스킬 본문이 `Skill` 툴로 부를 수 없다.** 실측: `Skill(short)` → `Skill short cannot be used with Skill tool due to disable-model-invocation`. 그 필드는 자동 발화만 막는 게 아니라 모델의 명시 호출도 막는다.

- **`/fask`** 는 그 플래그가 있다(인터뷰 스킬이 멋대로 발화하면 안 되므로). 그래서 이 스킬은 **fask 규약을 인라인으로 읽어 그대로 따른다.**
- **`/full-loop`** 은 이 체인이 끊기지 않도록 그 플래그를 **빼고**, 대신 description 으로 "직접 치거나 fask-loop 인계 직후만"으로 잠갔다. 그래서 마지막에 **`Skill` 툴로 바로 호출한다.** 세션의 스킬 목록이 낡아서 호출이 거부되면(플래그 제거 전 세션 등) `.claude/skills/full-loop/SKILL.md` 를 직접 Read 해서 그대로 따른다.

## 1. 캐묻는다

아래가 `/fask` 의 정본이다. 요약하지 말고 **그대로 따른다.**

```!
cat "${CLAUDE_PROJECT_DIR}/.claude/skills/fask/SKILL.md"
```

위 내용이 안 실렸으면 `.claude/skills/fask/SKILL.md` 를 직접 Read 해서 따른다. 그것도 없으면 fask 가 설치 안 된 것이므로 그렇게 알리고 멈춘다.

**fask 4단계의 안개 판정을 존중한다:**

- **안개 없음** → 2절로.
- **안개 있음** → fask 규약대로 `wayfinder` 로 `.scratch/` 에 맵을 만들고 **거기서 멈춘다.** 한 세션에 안 끝날 크기라는 판정이 방금 났는데 자율 루프에 던지는 건 그 판정을 무시하는 것이다. `/full-loop` 으로 넘기지 않는다.

## 2. goal 로 압축한다

질문이 마르면 합의된 내용을 **`/full-loop` 이 그대로 먹을 수 있는 한 덩어리**로 압축한다:

```markdown
목표: <한 문장 — 무엇이 되면 끝인가>

완료 조건:
- <증거로 확인 가능한 것만. "잘 동작한다" 금지. "<명령>이 0으로 끝난다" 형태로>

잠근 결정:
- <사용자가 고른 것 — 루프가 이걸 다시 정하면 안 된다>

범위 밖:
- <안 만들기로 한 것>

검증 명령: <0단계에서 확인된 실제 명령>
```

**완료 조건은 증거로 판정 가능해야 한다.** `/full-loop` 의 종료 판정과 중단 판정이 전부 여기에 걸린다. 애매하게 쓰면 루프가 언제 끝날지 스스로도 모른다.

**검증 명령을 여기서 같이 확정한다.** `/full-loop` 0단계 5번이 이걸 요구하고, 못 찾으면 시작 자체를 거부한다. 인터뷰가 끝난 지금이 확인하기 가장 싼 시점이다.

## 3. 호출한다

압축본을 보여주고 알린다: **여기서부터는 안 묻는다.** 루프 중에 새 결정이 나오면 `/full-loop` 이 스스로 정하고 `decisions.md` 에 기록한다. 그게 두 스킬의 계약이다.

그리고 **곧바로** `Skill` 툴로 `full-loop` 을 호출한다. 권한 모드 확인이든 뭐든 **사용자 답을 기다리는 단계를 여기 끼우지 마라** — 인터뷰가 끝난 순간부터 멈춤은 없다. auto 모드가 아니면 권한 프롬프트가 뜨는 것으로 사용자가 알게 된다. args 에 압축된 goal 을 통째로 넘긴다:

```
Skill(skill: "full-loop", args: "<압축된 goal>")
```

## 범위 밖

- **full-loop 규약 재정의** — 호출까지가 이 스킬이다. 루프의 진행·중단·재개는 전부 `/full-loop` 것이다
- **루프 중간에 다시 캐묻기** — 진입점일 뿐이다. 넘어간 뒤 규약은 `/full-loop` 것이다
- **fask 규약 재정의** — 정본은 `/fask` 다. 여기서 요약하거나 바꾸지 않는다
- **안개 있는데 루프 돌리기** — 맵이 나왔으면 거기서 멈춘다
