포트폴리오 페이지를 앰버 액센트 다크 테마로 리디자인해, 문구와 IA를 그대로 둔 채
첫 화면부터 출시작이 보이고 본문이 실제로 읽히는 상태로 만든다.

## 잠근 결정 (루프가 다시 정하지 않는다)

- hallmark 은 규칙 참고만. 스킬 설치 안 함
- 다크 테마 유지(#0f1011 계열). 페이지 전체 단일 테마, 섹션별 반전 금지
- 액센트는 앰버 `#f59e0b` 단일. 그라데이션·글로우 전면 금지
- 본문 Pretendard 유지 + JetBrains Mono 를 숫자·기간·카테고리 라벨·스택 태그에
- 히어로: 좌 텍스트 + 우 앱 아이콘 9개 비대칭 그리드. 모바일 단일 컬럼 붕괴
- 가독성 4항목 전부: 본문 크기 상향, 회색 의존 축소, 본문 폭 65자, 섹션 리듬 강화
- 시각층 + 섹션 내부 레이아웃만. 섹션 순서·앵커·네비 라벨·모든 문구 보존
- 프로젝트 카드 9장 동일 크기, 대표작 강조 없음, 썸네일은 앱 아이콘 유지
- 셰이프 락: 카드 12px / 컨트롤 8px / 칩 6px
- 모션 절제: transform·opacity 만, prefers-reduced-motion 준수

# 라운드 중 결정

## 한글이 섞인 문자열에는 모노를 쓰지 않는다

- 라운드: 2
- 고른 것: `greeting`, `project-category`, `employment-type`, 경력 숫자(`2년 8개월`)를 sans 로
  되돌리고, 모노는 순수 라틴/숫자에만 남겼다 (기간, 스택 카테고리, 스택 태그, SCG 제목, 연락처)
- 왜: JetBrains Mono 의 공백 글리프가 Pretendard 한글 글리프보다 넓다. 한 문자열 안에서 폰트가
  갈리면 "회사  프로젝트", "2년  8개월", "안녕하세요,  저는" 처럼 낱말이 벌어져 버그로 읽힌다.
  1440px 스크린샷에서 실제로 확인했다. 잠근 결정("모노를 숫자·기간·카테고리 라벨·스택 태그에")의
  대상은 전부 라틴/숫자라 이 제한과 충돌하지 않는다
- 안 고른 것: `word-spacing` 음수 보정 (폰트 크기마다 다시 맞춰야 함), 한글 모노 웹폰트 추가
  (D2Coding 등은 용량이 크고 잠근 결정이 JetBrains Mono 를 지정했다)

## 앱 아이콘에만 `--radius-icon: 22.5%` 를 추가한다

- 라운드: 2
- 고른 것: 셰이프 락(카드 12 / 컨트롤 8 / 칩 6)에 아이콘 이미지 전용 토큰 하나를 더했다
- 왜: iOS 앱 아이콘 스쿼클은 크기 비례(약 22.5%)라서 고정 px 로는 히어로 120px 아이콘과
  카드 60px 아이콘이 다른 모양이 된다. 퍼센트 토큰 하나로 두 크기가 같은 실루엣을 유지한다.
  UI 크롬이 아니라 콘텐츠 이미지에만 걸리므로 셰이프 락의 취지를 깨지 않는다
- 안 고른 것: 아이콘도 12px 카드 반경 (120px 아이콘에서 거의 직각으로 보임), 50% 원형
  (앱 아이콘 관례가 아님)

## 소개 본문을 카드에서 꺼낸다

- 라운드: 2
- 고른 것: `.bento-intro` 에서 `bento-card` 를 떼고 62ch 폭 제한만 남겼다. 숫자 3개는 카드
  3장이 아니라 카드 1장 안의 헤어라인 3행(`.stat-group`)으로 묶었다
- 왜: 읽는 글에는 상자가 필요 없고, 카드 5장이 나란한 화면은 격자가 균질해서 템플릿처럼 보인다.
  카드를 2장으로 줄이면 숫자가 시각적 주체가 되고 본문은 읽기 폭을 확보한다
- 안 고른 것: 5장 카드 유지 (가독성 목표와 어긋남), 본문도 카드로 두고 폭만 제한
  (상자 안 62ch 는 좌우 여백이 이중으로 생김)

## 검증 자산을 `.verify/` 에 두고 node_modules 는 커밋하지 않는다

- 라운드: 1
- 고른 것: Playwright 를 저장소 루트가 아니라 `.verify/package.json` 으로 설치하고
  `.gitignore` 에 `node_modules`, `shots` 를 넣었다
- 왜: 빌드 없는 정적 사이트라 루트에 package.json 이 생기면 프로젝트 성격이 바뀐 것처럼 보인다.
  검증 도구는 검증 폴더 안에 가둔다
- 안 고른 것: 세션 스크래치패드에 설치 (세션이 끝나면 사라져 재개 시 재설치),
  전역 설치 (다른 프로젝트에 영향)
